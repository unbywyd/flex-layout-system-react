## ⚠️ This Library is Deprecated

This library is no longer supported and is now redundant. The [flex-layout-system](https://www.npmjs.com/package/flex-layout-system) package now includes `jsx.types.d`. You can simply import the following:

```typescript
import "flex-layout-system/jsx.types.d"; // Import types
import "flex-layout-system"; // Import components
```
